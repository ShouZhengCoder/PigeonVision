# Pigeon Iris Kinship Dataset — 数据集卡（草稿，Phase B 定稿）

> 状态：Phase A 草稿。数值待 Phase B 最终校准。配合 CCF-B 表征学习论文贡献①（数据集定义 + 证明虹膜可判定血缘）。

## 1. 概述

- **名称（暂定）**：Pigeon Iris Kinship Dataset（信鸽虹膜血缘数据集）
- **任务**：基于虹膜图像判定信鸽个体间的血缘关系远近（细粒度亲缘度量学习）
- **来源**：信鸽影像数据（原始来自 chinaxinge 信鸽影像站，经教师提供整理），含原始鸽眼图、足环号、血统书原文
- **规模**：31,896 张原始鸽眼图 → 25,690 张成功归一化虹膜纹理图（64×512）；126,105 只鸽子的血统书记录

## 2. 组成

### 图像
- 原始鸽眼图 31,896 张（`data/extracted/1..12/*.jpg`，按数字 img_id 命名）
- YOLO 眼部裁剪 25,766 张
- U-Net 分割 + Daugman 椭圆展开 + iris mask 过滤后 64×512 三通道虹膜纹理图 25,690 张（success）

### 个体与血脉
- 113,844 条鸽子记录（`pigeon.csv`：ID/PID/CID/SID/NAME/COLOR/EYE/PG_ID/SEX/BLOOD/IMG），其中 PID/CID/SID 为分类码（省份/城市/鸽舍），非亲子
- 81,751 个唯一 blood_id（祖先个体足环号，如 `B98-3158062`）
- 每张图平均 4.85 个 blood_id，68% 图像有多重血脉

### 系谱（Stage 7 核心）
- `details.txt` 含 126,105 只鸽子的血统书原文，结构化字段：父亲/母亲/祖父/祖母/外祖父/外祖母 + 足环号
- 覆盖率：17,014(13.5%) 有 ≥1 角色字段，6,393(5.1%) 父母双全
- 可用虹膜集 25,690 张中：12,352(48%) 有 ≥1 角色字段，4,320(16.8%) 父母双全
- 族谱图（环号合法性过滤后）：53,158 节点 / 19,642 边 / 42,609 founder / 最大深度 8 / 最大连通分量 7,904
- 5 个真实记录错误环（已用路径内成环守卫规避）

## 3. 亲缘标签

- **形式 A（字符串祖先路径码）**：founder 唯一码 + 最近辈分，可解释
- **形式 B（亲缘系数 k(i,j)）**：`k = v_i·v_j`，`v[a] = Σ_path (1/2)^depth`，max_depth=6，≈2×标准亲缘系数 φ
- **覆盖**：结构化 3,806(14.8%) / relations.csv IDF 兜底 15,423(60.0%) / 无标签 6,461(25.2%)
- **单调性已验证**：全同胞 k=0.715 > 半同胞 0.400 > 表亲 0.104 > 无关 0.000
- **建议 tier**（Phase B 校准）：k>0.3 近亲 / 0.1–0.3 远亲 / <0.1 无关

## 4. 预处理 pipeline

Stage1 图片索引 → Stage2 YOLOv5 眼部检测裁剪 → Stage3 U-Net 虹膜分割 + Daugman 椭圆展开 + iris mask 过滤 → 64×512 三通道归一化图。详见 ROADMAP.md 阶段一至三。

## 5. 划分

- 干净切分：训练 17,983 / 验证 2,526（严格排除数据泄漏，按个体切分）
- 全量训练：25,690 张全部用于训练（生产部署方案）
- Phase B 起需新增：按亲缘 tier 分层的训练/测试划分，确保测试对的亲缘分布在训练中不可见

## 6. 预期用途

- 表征学习：训练虹膜编码器使其特征距离单调反映族谱亲缘 k
- 检索/比对：给定虹膜，返回 Top-K 血缘最近个体；判定两虹膜是否同血脉
- 学术：细粒度亲缘度量学习、多标签多正样本度量学习、族谱图监督的表征学习基准

## 7. 局限

- 结构化系谱覆盖率受 details.txt 角色字段稀疏限制（父母双全仅 5.1%）；60% 鸽子仅有扁平 blood_id 兜底
- 忽略 founder 自身近交 (1+F_a)，k 绝对尺度为近似（排序不受影响）
- 辈分深度上限 max_depth=6，深层祖先贡献截断（(1/2)^6=0.016，可忽略）
- 环号解析有噪声，已过滤畸形环但可能仍有少量错配
- 数据来源单一（chinaxenge），地理/品系分布可能有偏
